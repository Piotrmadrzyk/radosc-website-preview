i zamknięty. Pod adresem `/pm-growth-lab/` znajduje się teraz wyłącznie

(klucz `pmgl.michal.formularz.v1`). Nie dotyka żadnych innych danych
zapisanych w tej domenie.

Kompletna, ostatnia działająca wersja (`index.html`, `styles.css`,
`script.js`, poprzedni `README.md`) jest zachowana w archiwum:

- gałąź: `archive/pm-growth-lab-first-form`
- commit: `3ad2d1a863b79a392b0fd7621ee20d6c981488df`

Archiwum nie jest publikowane przez GitHub Pages — workflow publikuje
wyłącznie gałąź `preview/redesign-2026`.

Aby obejrzeć starą wersję lokalnie:

```bash
git checkout archive/pm-growth-lab-first-form -- pm-growth-lab/
```
